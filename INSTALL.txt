NetCheck · 网络体检 v1.2.0 安装说明
=========================================

系统要求
--------
macOS 14.0 或更高版本（已在 macOS 15.8 上验证）
本包为**通用二进制**，Intel 与 Apple Silicon（M 系列）均可原生运行。

安装
----
1. 解压本压缩包，得到「网络体检.app」
2. 把它拖进「应用程序」文件夹（或任意位置）

首次打开被系统拦截怎么办（重要）
--------------------------------
本 App 为免费开源软件，采用 ad-hoc 签名，未经 Apple 公证（公证需每年 99 美元的开发者账号）。
因此首次打开时 macOS 可能提示「无法打开，因为无法验证开发者」。三种解决方式任选：

方式一（推荐，图形界面）
    在「应用程序」里右键点击「网络体检.app」→ 选择「打开」→ 在弹窗里再次点「打开」。
    之后即可正常双击启动。

方式二（一行命令，去掉隔离标记）
    打开「终端」，粘贴执行：
        xattr -dr com.apple.quarantine "/Applications/网络体检.app"
    然后正常双击启动。

方式三（系统设置）
    「系统设置」→「隐私与安全性」→ 在下方看到被拦截的提示 → 点「仍要打开」。

关于定位权限
------------
首次运行会请求「定位权限」，用途仅有一个：macOS 14 起，不授权就无法读取 Wi-Fi 网络名称（SSID/BSSID）。
- 授权 → 显示 Wi-Fi 名称与精确加密方式
- 拒绝 → 显示「名称隐藏」，其余功能完全不受影响
本软件不会获取、存储或上传你的位置；所有测量都在本机完成，无任何联网上报。

可选依赖（缺失会自动降级，不影响主功能）
----------------------------------------
speedtest（speedtest-go）  Ookla 节点测速与上行测速通道
                           https://github.com/showwin/speedtest-go/releases
fping                      局域网存活探测加速
curl                       节点探测（系统自带）

使用
----
打开 App 后点首页「一键体检」，或从左侧直接进入各功能页：
本机测速 / 宽带节点测速 / 局域网设备 / Wi-Fi 检测分析 / 网络诊断
菜单栏会常驻显示实时上下行速率（↓x.x ↑x.x）。
